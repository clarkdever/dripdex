# DripDex

DripDex is a mobile-first Texas Hill Country field guide and personal nature journal. It is designed as a Pokédex-inspired way for kids, families, and adults to discover local creatures, record observations, and learn from cited naturalist sources.

The current repo contains the initial product design notes and visual inspiration references.

## Local Development

Install dependencies and start the app:

```bash
npm install
npm run dev
```

Useful checks:

```bash
npm run lint
npm run typecheck
npm test
npm run build
```
