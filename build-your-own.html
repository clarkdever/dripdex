Local preview

Run it on your computer.

These commands clone the repo, install dependencies, and start the Next.js development server. 

git clone https://github.com/clarkdever/dripdex.git
cd dripdex
npm install
npm run dev

Open the local URL printed by the dev server, usually http://localhost:3000.

To preview the owner journal locally, copy the safe env template and keep real values in the ignored local file:

cp .env.example .env.local
read -s OWNER_PASSWORD
printf '%s' "$OWNER_PASSWORD" | npm run owner:hash
unset OWNER_PASSWORD

Put the generated password hash, a long auth secret, and optional AI provider keys in .env.local. Do not paste secrets, password hashes, API keys, or screenshots of env files into chat, issues, docs, or README examples.

Vercel Hobby

Publish the fixture-backed preview.

Vercel can import a GitHub repository, detect Next.js, and produce a public preview URL.

Create or sign into GitHub.
Create or sign into Vercel using https://vercel.com/signup.
Fork or copy clarkdever/dripdex into your GitHub account.
In Vercel, import the GitHub repository as a new project.
Let Vercel detect the Next.js project settings and deploy.
If enabling owner auth or real AI testing, fill .env.local, run npm run vercel:env:sync to review names, then apply with npm run vercel:env:sync -- --apply --confirm-project prj_your_project_id after checking the linked project id.
Redeploy production after Vercel env changes so the new values are available.
Open the Vercel URL and confirm the public collection page loads.
