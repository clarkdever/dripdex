DripDex

A mobile-first field guide and personal nature journal for families, classrooms, clubs, and curious local naturalists.

Build a preview Read the privacy model

What it is

A playful guide with serious privacy boundaries.

DripDex is designed to make local discovery feel approachable for kids while staying useful for adults who care about sources, observations, location privacy, and safe publishing.

Public

Creature cards

Visitors browse fixture-backed creature cards, kid-readable facts, rarity-style tags, and public-safe image derivatives.

Owner

Private journal

The intended owner workflow keeps drafts, exact locations, private originals, and moderation tools behind owner-only boundaries.

Open source

Self-hostable core

The first open-source path is a single-owner field journal with fixture-backed preview data and conservative hosting assumptions.

Current MVP status

Preview the shape before real uploads.

The current repo is a fixture-backed MVP preview. It can show public browsing, creature pages, capture stubs, mystery investigation views, private journal previews, and guestbook moderation states.

Good fit today: public demos, contributor previews, family/classroom evaluation, and static project documentation.
Not ready yet: real private uploads, durable SQLite writes, private original storage, exact GPS hosting, or production auth.
